# Office Analytics — аналитика активности сотрудников по видео

Программа смотрит на видео с камеры, **опознаёт зарегистрированных сотрудников по лицу**, определяет, что каждый делает, и ведёт учёт времени по состояниям персонально. Всё работает локально: видео не записывается и не уходит в сеть; в базе — интервалы («Петров, работает за столом, 09:12–10:40») и числовые векторы лиц (фото не хранятся).

## Что распознаёт

| Состояние | Как определяется |
|---|---|
| Работает за столом | в зоне «Рабочее место», сидит, есть движение |
| Сидит без активности | то же, без движения дольше 45 с (настраивается) |
| Стоит у стола / Подходит к столу | стоит в зоне стола / идёт к ней |
| У складского стеллажа / Идёт к стеллажу | в зоне «Складской стеллаж» / движется к ней |
| В зоне отдыха | в зоне «Зона отдыха» |
| Идёт, Стоит, Сидит | вне зон |
| Отошёл (туалет) / Вышел из помещения | пропал рядом с зоной-дверью «Туалет» / «Выход» |
| Нет в кадре | пропал в другом месте |

## Установка

**Windows:** Python 3.10–3.12 (галочка «Add Python to PATH») → `install.bat` (один раз, нужен интернет) → `start.bat`.
**Linux/ARM:** `./install.sh` → `./start.sh`.
Слабое устройство (маломощный контроллер): `install.bat lite` / `./install.sh lite` — без YOLO и torch (позу тела определяет упрощённо, лица работают так же).

Интерфейс: http://localhost:8080 (с других ПК сети — по IP этого устройства; пароль — «Настройки → Доступ», логин `admin`).

## Распознавание лиц

Модели лиц (YuNet и SFace из OpenCV Zoo, ~10 МБ) уже лежат в папке `models/` — скачивать ничего не нужно. Если файлы пропали или повредились: `python download_models.py`; если скачивание не проходит (прокси, блокировка GitHub) — скачайте два файла в браузере по ссылкам из `models/README.txt`, положите в `models/` (имена не менять) и проверьте `python download_models.py --check`. Сообщение «Модели лиц не скачались» не мешает работе: программа просто работает без опознавания по лицу.

1. Вкладка **«Сотрудники»** → ФИО, должность, галочка «есть письменное согласие» (без неё сотрудник не добавляется) → **Добавить**.
2. **«Снять с камеры»**: человек 4–5 секунд смотрит в камеру, слегка поворачивая голову (в кадре должно быть одно лицо), либо **«Загрузить фото»** (2–5 чётких фото анфас). Делайте это при том освещении, в котором камера работает обычно.
3. Дальше система сама опознаёт человека в кадре и ведёт учёт под его именем. Пока человека не опознали (по умолчанию до 12 с), он идёт как «Неизвестный #N»; после опознания вся накопленная запись переносится сотруднику. Когда он уходит и возвращается — опознаётся заново и учёт продолжается.
4. **Отозвать согласие** — удаляет лица сотрудника; **Удалить** — удаляет сотрудника (по выбору с историей активности).

Защита от ошибок: опознание только после нескольких совпадений подряд; если лицо похоже на двух сотрудников, оно считается неопределённым; нельзя зарегистрировать одно лицо на двух людей; каждые 10 с личность перепроверяется.

### Что нужно для нормальной работы лиц (важно)
- **Размер лица в кадре не меньше ~60–80 пикселей по ширине.** Камера в углу под потолком на 6–8 м часто даёт лица в 20–40 px — этого мало. Решения: камера 1080p/4K, установка ниже и ближе к рабочим местам/проходам, лицом к потоку людей (у двери, у стеллажей), в «Настройках» увеличить «Размер кадра для лиц» (профиль «Высокий»).
- Каски, респираторы, маски, очки закрытого типа, сильный контровой свет, взгляд вниз на стол — лицо не опознаётся. Тогда человек остаётся «неизвестным» до момента, когда повернётся к камере. Для спецодежды и СИЗ точность нужно проверить на месте.
- Если лица в кадре мелкие, ставьте отдельную камеру на входе: опознанный человек дальше ведётся по телу.

## Режим для ПЛК / панельного ПК с экраном

Программа рассчитана на промышленный контроллер или панельный ПК с ОС Windows или Linux (x86 или ARM) и подключённым дисплеем. **Классический ПЛК без полноценной ОС (Siemens S7, CODESYS-рантайм и т.п.) её запустить не может** — для него нужен отдельный панельный ПК рядом.

- **Экран:** `start_kiosk.bat` (Linux: `./start.sh --kiosk`) — сервер и полноэкранная панель на дисплее: карточки сотрудников с текущим состоянием и временем, «на месте / работают», статус камеры, видео с рамками. Нажатие на видео скрывает его (экономит ресурсы). Если браузер закрыть или он упадёт — перезапустится сам. Нужен Chromium, Chrome или Edge.
- **Автозапуск Windows:** `autostart_kiosk_on.bat` (отключить — `autostart_off.bat`); включите автовход пользователя в Windows.
- **Автозапуск Linux:** `sudo ./install_service.sh [light|standard|high]` — служба systemd (стартует при включении, перезапускается при сбое) + панель после входа в графическую сессию (включите автовход).
- **Нагрузка:** профиль выбирается в «Настройки → Производительность» или ключом `--profile light`. «Лёгкий» — 2 кадра анализа/с, уменьшенное изображение; подходит для Celeron/Atom и ARM-плат. На слабом железе начните с него и `install lite`, если установка YOLO не проходит или идёт медленно.
- Панель можно открыть и на другом экране в сети: `http://IP-контроллера:8080/panel`.

## Подключение камеры («Настройки → Источник видео»)
- **Веб-камера ПК / USB-камера** — для проверки или без Wi-Fi камеры.
- **Wi-Fi / IP-камера** — адрес потока, напр. `rtsp://логин:пароль@192.168.1.50:554/stream1` или `http://192.168.1.50:8080/video`. Включите RTSP в настройках камеры; точный путь смотрите в инструкции модели.
- **Видеофайл** — для проверки без камеры.
При обрыве связи программа переподключается сама.

## Первая настройка
1. **Зоны:** обведите столы, стеллажи, зону отдыха и **двери** туалета/выхода (рамкой вокруг проёма).
2. **Сотрудники:** добавьте людей и снимите лица.
3. **Отчёты:** сводка по каждому сотруднику (в кадре, работал, %, отсутствие, выходы, туалет), цветная хронология, CSV для Excel.

## Ограничения
- Система видит позу и движение, а не содержание работы: «работает» = «сидит за столом и двигается».
- Распознавание лиц — вероятностное; возможны ошибки (особенно при плохом свете, СИЗ, маленьких лицах и похожих людях). Результаты нельзя считать безошибочными и использовать как единственное основание для дисциплинарных мер.
- Туалет определяется косвенно: человек пропал у двери туалета.
- Автоматического теста с реальными моделями лиц и реальной камерой при сборке не проводилось (модели скачиваются на вашем ПК): первые дни проверьте работу на живых людях и подберите порог схожести.

## Юридически важно (РФ)
Изображение лица для опознания — **биометрические персональные данные**. Для них нужно **письменное согласие** каждого сотрудника (ст. 11 152-ФЗ), уведомление работников о видеонаблюдении и учёте (ст. 86–90 ТК РФ), локальный акт о порядке обработки и хранения, определение срока хранения (в программе: «Хранить данные, дней»), при необходимости — уведомление Роскомнадзора. Отметки о походах в туалет — особо деликатные. Сотрудник вправе отозвать согласие — для этого есть кнопка. Согласуйте использование с юристом до запуска в работу; программа лишь требует отметить наличие согласия и не заменяет его оформление.
